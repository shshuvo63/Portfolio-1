## About the Project

**Mary Hardy Portfolio Website** is a clean and modern personal portfolio website designed to present a developer's professional profile, technical skills, projects, and contact information.

The website includes a hero section, personal information, technical skills, project gallery, social media links, and a contact form. It is built using fundamental web technologies with a focus on clean structure and user-friendly design.

---

## Project Overview

The main purpose of this project is to create a professional personal portfolio that can be used to:

* Introduce the developer and their professional background
* Showcase technical skills and technologies
* Display completed projects
* Provide personal and professional information
* Allow visitors to contact the developer
* Provide links to social media profiles

### Main Sections

* **Navbar** — Portfolio navigation and Hire Me button
* **Hero Section** — Introduction, profile image, CV download, and contact button
* **About Me** — Personal information and professional description
* **What I Do** — Technical skills and technologies
* **My Amazing Works** — Project/image gallery
* **Footer** — Social media links and contact form

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/mary-hardy-portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd mary-hardy-portfolio
```

### 3. Open the Project

Open the project folder in **Visual Studio Code**.

### 4. Run the Website

You can open `index.html` directly in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.
